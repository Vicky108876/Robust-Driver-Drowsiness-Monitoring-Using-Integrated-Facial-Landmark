+-----------------------------------------------------------------------+
| Robust Driver Drowsiness Monitoring Using Integrated Facial Landmark  |
+-----------------------------------------------------------------------+

    1. Input Source
        * Live Video Capture using OpenCV (Webcam)
        * Real-time frame processing

    2. Preprocessing
        * Frame conversion (BGR → RGB)
        * Face detection using MediaPipe Face Mesh
        * Extraction of 468 facial landmarks
        * Face bounding box generation
        * Temporal smoothing using buffer (deque - size 15)

    3. Feature Extraction
        * Eye Aspect Ratio (EAR)
            -> Computed using 6 eye landmark points
            -> Detects eye closure / microsleep
        * Mouth Aspect Ratio (MAR)
            -> Computed using mouth landmarks
            -> Detects yawning
        * Smoothed Features:
            -> Mean EAR over 15 frames
            -> Mean MAR over 15 frames
        * Final Feature Vector:
            -> [EAR_mean, MAR_mean]

    4. Head Pose Estimation (Rule-Based)
        * Key landmarks:
            -> Nose, Left Face, Right Face, Top, Bottom
        * Computed Ratios:
            -> Horizontal Ratio (Left vs Right)
            -> Vertical Ratio (Top vs Bottom)
        * Head States:
            -> Looking Left
            -> Looking Right
            -> Looking Up
            -> Looking Down
            -> Forward (Normal)

    5. Feature Scaling
        * Standardization using pre-trained scaler
        * Ensures consistent input to model

    6. Classification
        * Model: Multi-Layer Perceptron (MLP)
        * Input Features:
            -> EAR_mean
            -> MAR_mean
        * Output Classes:
            -> Alert
            -> Microsleep
            -> Yawning

    7. Decision Logic
        * Drowsiness detected if:
            -> Microsleep OR Yawning (MLP Output)
            OR
            -> Abnormal Head Pose (Rule-Based)
        * Combined hybrid approach:
            -> Machine Learning + Rule-Based

    8. Alert System
        * Audio alert using Pygame mixer
        * Triggered when:
            -> Drowsy state detected
            OR
            -> Abnormal head movement detected

    9. Visualization Dashboard
        * Real-time UI panel displaying:
            -> Driver State (Alert / Drowsy)
            -> Head Pose Status
            -> EAR value
            -> MAR value
        * Alarm indicator display
        * Face mesh overlay visualization

    10. Output
        * Real-time driver state prediction
        * Audio warning alert
        * Screenshot capture option (Key: 's')
            -> Saves frame with timestamp

    11. Tools & Libraries Used
        * OpenCV
        * MediaPipe
        * NumPy
        * Pandas
        * Scikit-learn (MLP, Scaler, Label Encoder)
        * Pygame (Audio Alert)
        * Joblib (Model Loading)

    12. System Type
        * Hybrid Approach:
            -> Feature-based ML (EAR, MAR)
            -> Rule-based Head Pose Detection
        * Real-time, non-intrusive system
